## 주요 성과
- O₂ 가상센서 정확도 **RA 98.6%**
- 센서 고장 탐지 정확도 **97~99%**
- FAT 기간 실제 공정 이상 **5건 탐지**
- CO 센서 검정 정확도 **RA 99.0~99.8%**
- CO 예측 오차 **0.124~0.793 ppm**
- O₂ 예측 성능 **R² 47.7% → 85.4% 개선**

## 이런 일을 합니다
- 공정 데이터를 분석해 **가상센서**와 **이상진단 로직**을 설계합니다.
- 리샘플링, 보간, 노이즈 필터링, 비가동 구간 제외 등 **전처리 파이프라인**을 구축합니다.
- PCA / SPE, Band-width, 회귀 모델 등을 활용해 **센서 건전성**을 판단합니다.
- 열수지 기반 입·출열 계산으로 **연소 효율 / 열정산 모니터링** 로직을 구현합니다.
- 분석 결과가 현장에서 바로 활용될 수 있도록 **운영 로직과 예외 처리**를 함께 설계합니다.

## 업무 스타일
- 데이터 정합성을 먼저 해결한 뒤 모델링을 진행합니다.
- 예측 정확도만이 아니라 운영 가능한 규칙, 예외 처리, 모니터링 구조까지 함께 설계합니다.
- 수치 성과와 현장 적용 가능성을 동시에 검증합니다.
